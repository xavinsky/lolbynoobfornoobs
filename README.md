# LoL by Noob for Noobs

Un guide de League of Legends pensé pour les débutants, par un débutant : pages statiques, sans serveur, publiées sur GitHub Pages. Chaque valeur affichée a sa source et sa règle de calcul sur la page **Sources** du site.

Ce dépôt est **généré** depuis un brouillon privé (`tools/build_public.sh` du projet d'origine) : il n'est pas édité à la main.

**Contenu** : liste et fiches des champions (compétences, mécaniques, vidéos de présentation, mises à jour, courbe de puissance), classification des compétences, objets, effets et statistiques des objets, sources.

**Données** : Data Dragon (Riot Games), wiki League of Legends (textes sous licence [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), pages citées sur le site), op.gg, lolalytics — détail et dates sur la page Sources.
