# Contribuer à LoL by Noob for Noobs

Toute contribution est la bienvenue ❤️ Le site est fait par un noob : il a besoin de ceux qui connaissent le jeu, et aussi des autres débutants.

- **Une erreur, même un détail** : chiffre, explication, traduction, page peu claire. Ouvre une issue « Signaler une erreur ».
- **Une idée ou une meilleure explication** : un counter mieux expliqué, une source, une nouvelle page ou fonctionnalité. Ouvre une issue « Proposer une idée ou participer ».
- **Participer au code ou aux données** : dis-le dans une issue avant de te lancer. Ce dépôt est généré depuis un brouillon de travail et n'est pas édité à la main, on voit ensemble comment intégrer ta contribution.

Pas de compte GitHub ? Le site propose un formulaire sans compte : section « Contribuer » de la page Sources, ou le lien « ✍️ Signaler une erreur ou proposer mieux » sur chaque fiche et chaque counter.
